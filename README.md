# Account Timer

A simple Windows desktop application for managing multiple accounts with automatic reset timers.

## What It Does

Account Timer helps you track multiple accounts for any service or platform. Set a timer for each account to know exactly when it becomes available again after use.

Perfect for managing:
- Trial accounts with cooldown periods
- Rate-limited service accounts
- Rotating social media accounts
- Any accounts with time-based restrictions

## Features

- **Multiple Account Lists** - Organize accounts into separate lists
- **Countdown Timers** - Track when each account becomes available
- **Flexible Duration** - Set reset periods (1 week, 2 weeks, 1 month, or custom)
- **Suspend/Resume** - Pause timers when needed
- **Status Tracking** - See at a glance which accounts are available or in use

## Requirements

- Windows 10 or later
- .NET 8.0 Runtime

## How to Use

1. Create a list for your accounts
2. Add account emails to the list
3. Start a timer when you use an account
4. The timer shows when that account will be available again
